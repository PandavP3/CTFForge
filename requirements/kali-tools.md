# Optional Kali/Linux tools

These are external programs, not Python packages. CTFForge only detects them; it does not install them.

| Tool | Common use |
| --- | --- |
| nmap | Network and service enumeration in authorized labs |
| tshark | Packet capture analysis |
| wireshark | Interactive packet analysis |
| binwalk | Embedded-file and firmware inspection |
| exiftool | Metadata inspection |
| ffuf | Web content discovery in authorized labs |
| nuclei | Template-based checks in authorized labs |
| ghidra | Reverse engineering |
| jadx | Android decompilation |
| apktool | Android package inspection |
| volatility3 | Memory forensics |
| ROPgadget | ROP gadget discovery |
| sqlmap | SQL injection testing in authorized labs |
